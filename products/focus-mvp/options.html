Vannevar 账号

登录后可开启跨设备云同步（Focus + Muse + Bridge 数据协同）。未登录时仅使用本地存储。

已登录：

数据同步

登录后可将本地快照同步到 Bridge 云端，实现跨设备数据协同。

E2E 加密同步

启用后，快照在本地用 AES-GCM-256 加密后再上传，Bridge 服务器永远无法看到明文。passphrase 仅保存在内存，浏览器或扩展重启后需重新输入。

⚠ 忘记 passphrase 将无法恢复云端密文。请将 passphrase 保存在密码管理器或离线介质中。salt 与校验密文存储在本地，无法反推 passphrase。

Bridge 项目关联

选择一个 Bridge 项目作为推送目标。在弹出页中点击「推送到 Bridge」按钮时，快照将归档到此项目。
加密边界：「数据同步」走端到端加密（Bridge 只存密文），但「推送到 Bridge 项目档案」不加密 —— Bridge 需要读取标题、链接与摘要来生成交接摘要和统计图表。

Bridge 任务通知

每 5 分钟检查 Bridge 上你所属项目的任务变更（状态、负责人等），并通过系统通知和角标提醒你。需先登录 Bridge 账号。

数据管理

导出您的全部快照为 JSON 文件用于备份，或从备份文件恢复快照。

AI 增强（可选）

可选功能。配置后，Resume 摘要将由 AI 生成，更精准更智能。不配置则使用内置规则引擎。API Key 仅保存在本地 chrome.storage.local，不上传任何服务器。

⚠ API Key 以明文存储于本地浏览器，仅在本设备使用，不会上传到任何服务器。清除浏览器数据将一并清除。

开启后无需配置 API Key 即可体验 AI 增强效果，使用预设结果演示

端侧本地模型（实验性）

基于 WebGPU 在本地运行小型语言模型，数据不出设备。适合隐私敏感场景的轻量建议生成。首次加载约 600MB 模型，需 Chrome 113+ 且支持 WebGPU。

⚠ 本地模型推理仅在 options/popup 页面进行（Service Worker 不支持 WebGPU）。推理时请保持窗口打开，关闭窗口会中断推理。

隐私说明

数据存储说明：所有快照内容（含页面 URL、标题等）均以 Base64 编码存储在本地浏览器 chrome.storage.local 中。Base64 不是加密，本地文件系统的访问者可直接解码读取。请勿在公用设备上保存敏感页面的上下文。
  • 所有数据存储在本地浏览器，未启用 E2E 加密时，云端同步数据对 Bridge 服务器可见
  • 启用 E2E 加密后（AES-GCM-256 + PBKDF2-SHA256，100,000 次迭代），快照在本地加密后再上传，Bridge 服务器永远只能看到密文；passphrase 不上传、不持久化，仅派生 key 存内存（non-extractable）
  • 数据库以 SQLite 形式保存在 chrome.storage.local，本地存储本身未加密（如需本地加密请使用浏览器主密码或全盘加密）
  • 导出文件包含您的全部快照明文，请妥善保管；忘记 E2E 加密 passphrase 将无法恢复云端密文

数据与隐私

⚠️ 数据备份提示

Focus 的快照数据存储在浏览器本地（SQLite WASM + chrome.storage.local）。浏览器更新、扩展冲突或清除浏览数据可能导致数据丢失。建议定期使用「导出为 Context Card」功能备份重要快照。

故障排查 FAQ

Q：更新浏览器后 Focus 数据丢失了？

A：Chrome 大版本更新偶尔会重置扩展存储。检查 chrome://settings/content/all 确认 Focus 扩展的存储权限。如果数据已丢失，从之前的 Context Card 备份导入恢复。

Q：Focus 扩展图标不显示？

A：在 chrome://extensions 确认 Focus 已启用。如果扩展被禁用，重新启用后数据会恢复。如扩展被卸载，数据会一同丢失——这是 Chrome 的机制，无法避免。

Q：与其他扩展冲突？

A：如果 Focus 与其他标签管理扩展冲突，尝试在冲突场景下只启用 Focus。Focus 仅使用 tabs/storage/windows 权限，不修改网页内容，冲突概率低。

Q：快照恢复时部分标签打不开？

A：Focus 仅恢复 http/https 链接，过滤危险 scheme。如果原标签是 chrome:// 内部页面或已失效的 URL，会自动跳过。检查快照详情中的 URL 列表。

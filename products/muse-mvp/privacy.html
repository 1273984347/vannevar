隐私政策

最后更新：2026 年 7 月 8 日

本隐私政策适用于 Vannevar 产品族（Focus、Muse、Bridge）。我们采用「本地优先」架构，您的数据默认存储在您自己的设备和浏览器中，不上云、不外传。

核心承诺：Vannevar 不收集、不上传、不分享您的个人数据。所有用户数据默认存储在浏览器本地（chrome.storage.local）或本地数据库文件中。

一、适用产品

Focus
浏览器扩展，保存并恢复工作上下文（标签页快照）
Muse
浏览器扩展，捕捉网页灵感片段与氛围标签
Bridge
Web 服务，公益项目任务看板与志愿者交接

二、数据收集与存储

2.1 Focus / Muse（浏览器扩展）

  • 存储位置：所有数据存储在浏览器本地的 chrome.storage.local，使用 SQLite WASM（sql.js）以 Base64 编码形式持久化。
  • 存储内容：用户主动保存的标签页快照（Focus）/ 灵感片段（Muse），包括页面标题、URL、选中文本、用户标注。
  • 存储配额：受 Chrome 浏览器 chrome.storage.local 配额限制（约 10MB，已声明 unlimitedStorage 权限可突破此限制）。
  • 不上传：扩展不会将任何用户数据发送到我们的服务器或任何第三方服务器。
  • Service Worker 生命周期：MV3 Service Worker 被浏览器休眠后，数据不会丢失——重新唤醒时从 chrome.storage.local 重新加载 SQLite 数据库。

2.2 Bridge（Web 服务）

  • 存储位置：项目数据存储在服务器本地 SQLite 文件（bridge_mvp.db），不上云。
  • 存储内容：管理员创建的项目、任务、留言、交接摘要。
  • 访问控制：管理员操作需 Basic Auth 认证；志愿者视图通过项目专属二维码 Token 访问，仅可查看未删除的留言和任务。
  • 内容审核：留言提交时调用本地敏感词检测（violence/spam 两类），命中则标记但不阻止提交；管理员可软删除不当留言。

三、AI 功能与第三方服务

Vannevar 的 AI 功能（上下文标签、氛围推荐、交接摘要）为可选增强，核心功能不依赖 AI。

3.1 Focus / Muse 的 AI 调用

  • 用户主动配置：用户需在 Options 页面主动填写 OpenAI 兼容 API 的 Base URL、API Key、模型名才会启用 AI 功能。
  • 直连服务商：AI 请求由浏览器扩展直接发送到用户配置的 API 服务商（如 OpenAI、DeepSeek、Moonshot、SiliconFlow），不经过我们的服务器中转。
  • 受服务商政策约束：用户与 AI 服务商之间的数据交互受该服务商隐私政策约束。Vannevar 不存储、不中转、不审计 AI 请求内容。
  • 降级策略：未配置 API Key 或请求超时（30 秒）时，自动降级到本地规则引擎，核心功能完全可用。
  • 演示模式：Options 页提供「演示模式」开关，开启后使用预设结果展示 AI 效果，不发起任何外部请求。

3.2 Bridge 的 AI 调用

  • 服务器端配置：管理员通过环境变量（BRIDGE_AI_BASE_URL / BRIDGE_AI_API_KEY / BRIDGE_AI_MODEL）配置 AI 服务。
  • 请求内容：交接摘要生成时，会将项目任务标题、留言内容发送到配置的 AI 服务商以生成摘要。
  • 免责提示：AI 生成的交接摘要旁标注「⚠️ 此摘要由 AI 生成，仅供参考，请务必核对原始任务和留言」。
  • 降级策略：未配置或超时时降级到规则引擎结构化模板。

提示：配置 AI 功能后，您的数据将按照所配置 AI 服务商的隐私政策处理。请审慎评估服务商合规性。

四、数据使用

  • 仅用于产品功能：所有数据仅用于实现产品本身的功能（保存、恢复、搜索、导出、AI 增强）。
  • 不用于分析：Vannevar 不进行用户行为分析、不埋点、不上传统计数据。
  • 不用于广告：Vannevar 不展示广告，不与广告商共享数据。

五、数据分享

  • 不与第三方分享：除用户主动配置的 AI 服务商外，Vannevar 不与任何第三方分享用户数据。
  • 用户主动导出：用户可通过产品内的「导出」功能将数据导出为 Vannevar Context Card（.vcf）或 JSON 格式自行分享，分享行为由用户自主决定。
  • 法律要求：在法律法规明确要求的情况下，可能需要配合披露必要数据，但 Vannevar 的本地优先架构决定了我们能披露的数据极为有限。

六、用户权利

  • 访问权：用户可随时在产品内查看所有已保存的数据。
  • 导出权：用户可一键导出全部数据为 JSON 或 Context Card 格式。
  • 删除权：用户可删除单条记录或清空全部数据，删除立即生效且不可恢复（Bridge 留言软删除保留审计痕迹）。
  • 不追踪权：Vannevar 不追踪用户行为，无需「退出追踪」操作。

七、数据安全

  • 本地存储：数据存于浏览器本地，受浏览器自身的安全沙箱保护。
  • 扩展隔离：扩展的数据存储受 Chrome 扩展隔离机制保护，其他扩展无法访问。
  • XSS 防护：所有用户输入在渲染前经过 escapeHtml 转义。
  • CSP 策略：扩展页面配置严格的 Content Security Policy，限制脚本来源。
  • URL Scheme 白名单：Focus 恢复快照时仅允许 http/https 协议，过滤危险 scheme。
  • Bridge 安全加固：Basic Auth + CSRF 双重提交 Cookie + IDOR 防护 + 路径遍历防护。

八、儿童隐私

Vannevar 不面向 13 岁以下儿童。我们不会故意收集儿童的个人信息。如果您是儿童的监护人，发现儿童提供了个人信息，可通过 GitHub Issues 联系我们删除。

九、隐私政策变更

本政策可能随产品迭代更新。重大变更会在产品内通过通知或 GitHub Release Notes 告知用户。继续使用产品视为接受更新后的政策。

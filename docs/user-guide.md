# Vannevar 用户指南

## 三产品概览

| 产品 | 定位 | 平台 |
|------|------|------|
| **Bridge** | 统一后端 + 管理后台 | Web（FastAPI） |
| **Focus** | 上下文管理扩展 | Chrome MV3 |
| **Muse** | 灵感管理扩展 | Chrome MV3 |

---

## Bridge 快速上手

### 1. 创建项目

1. 访问管理后台首页
2. 填写项目名称和描述
3. 点击创建

### 2. 邀请志愿者

1. 在项目详情页找到二维码
2. 志愿者扫码进入项目视图
3. 志愿者可记录待办、查看任务

### 3. 任务协作

- **创建任务**：项目详情页 → 添加任务
- **更新状态**：todo → in_progress → done
- **记录交接**：班次结束记录交接摘要
- **留言沟通**：项目内留言板

### 4. 账号系统

- **注册**：邮箱 + 密码
- **登录**：获取 JWT token（7 天有效期）
- **项目隔离**：个人项目仅创建者可访问

### 5. 组织管理

- **创建组织**：设置名称和 slug
- **邀请成员**：通过邮箱邀请
- **团队管理**：组织内创建团队
- **项目共享**：创建项目后，通过 `POST /api/projects/{id}/shares` 共享给组织/团队/个人（支持 view/edit 权限）

## Focus 扩展指南

### 核心功能

1. **快照保存**：一键保存当前所有标签页
2. **上下文恢复**：恢复之前保存的标签页组
3. **AI 摘要**：自动生成会话摘要
4. **Agent 建议**：主动提醒停滞任务

### 使用流程

1. 点击工具栏 Focus 图标
2. 查看当前标签页列表
3. 点击「保存快照」
4. 输入快照名称
5. 下次恢复时从列表选择

### 配置

- 访问扩展选项页（右键图标 → 选项）
- 配置 Bridge 服务器地址
- 配置 AI API（可选）
- 配置端侧本地模型（实验性，需 WebGPU）

---

## Muse 扩展指南

### 核心功能

1. **灵感记录**：快速记录想法和心情
2. **心情追踪**：记录情绪变化
3. **AI 摘要**：灵感整理
4. **Agent 建议**：灵感回顾提醒

### 使用流程

1. 点击工具栏 Muse 图标
2. 记录当前灵感
3. 选择心情标签
4. 保存

## 数据同步

### 登录后自动同步

1. 在 Focus/Muse 选项页登录 Bridge 账号
2. 登录后自动启用云同步
3. 本地数据自动推送到 Bridge
4. 多设备登录可拉取数据

### 未登录模式

- 仅本地存储（chrome.storage.local）
- 数据不离开设备
- 登录后可一键迁移到云端

## AI 增强

### 三级降级策略

1. **云端 AI**（最高优先级）：OpenAI 兼容 API
2. **端侧本地模型**（次优先）：WebLLM + WebGPU
3. **规则引擎**（兜底）：纯本地统计

### 配置云端 AI

在 Bridge 或扩展选项页配置：
- API Base URL
- API Key
- 模型名称

### 配置端侧模型

> **V1 限制说明**：端侧本地模型为实验性功能，当前版本未打包 WebLLM 库（MV3 CSP 阻止远程脚本加载），暂不可用。请使用云端 AI 或规则引擎。未来版本将通过本地打包 WebLLM 重新启用。

1. 在扩展选项页启用「端侧本地模型」
2. 选择模型（Llama-3.2-1B / Phi-3.5-mini 等）
3. 等待下载完成
4. 自动在 SW 不可用时降级使用

## 常见问题

### Q: 忘记密码怎么办？
A: Bridge MVP 阶段暂不支持密码找回，请联系管理员重置。

### Q: 数据同步失败？
A: 检查网络连接、Bridge 服务是否运行、JWT token 是否过期。

### Q: AI 功能不工作？
A: 未配置 AI 时自动降级到规则引擎，属正常行为。配置 AI 需要有效的 API Key。

### Q: 端侧模型加载失败？
A: 当前版本未打包 WebLLM 库（V1 限制），端侧本地模型暂不可用。请改用云端 AI 或规则引擎。未来版本将通过本地打包 WebLLM 重新启用，届时需确保 Chrome 113+ 且启用 WebGPU。

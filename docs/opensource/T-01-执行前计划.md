## 2. 背景与事实基础

### 2.1 项目本体

Vannevar 是一套「上下文管理」产品族，致敬 Vannevar Bush 的 Memex 概念（1945 年《As We May Think》）。三个产品覆盖同一条上下文生命周期的三个阶段：

| 产品 | 形态 | 技术栈 | 阶段 |
|---|---|---|---|
| Focus | Chrome MV3 扩展 | 原生 JS + sql.js(WASM) + chrome.storage | 捕捉 |
| Muse | Chrome MV3 扩展 | 原生 JS + sql.js(WASM) + chrome.storage | 整理 |
| Bridge | FastAPI Web 服务 | FastAPI + SQLAlchemy + SQLite(WAL) + Jinja2 + SSE | 交接 |

统一内核：本地优先存储；统一 AI 降级策略（OpenAI 兼容 API，30s 超时/未配置 → 本地规则引擎）；共享设计系统 `shared/vannevar-brand.css`。

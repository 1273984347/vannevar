# T-12 · LAYA 决策模型供应链审查 + 受控评测 · 执行前计划

- 日期：2026-11-03
- 执行者：AI Agent（ZCode）
- 触发：用户决议「那就做」+ 明确要求「先审查官方仓库，不下载危险内容或病毒」

## 1. 目标

1. 对 LAYA（候选：`github.com/NandhaKishorM/laya`，社区口径：Convai Innovations 开源的 421M System 1 决策模型，Apache 2.0）做**安装前供应链安全审查**，审查通过才允许下载权重与安装；
2. 在隔离临时环境中完成**受控评测**：Bridge「任务状态建议」「留言审核」两个判断点，LAYA vs 现有规则引擎的准确率/延迟对比；
3. 依据预设判据产出「接入 / 不接入」决策与报告。

## 2. 审查清单（ST-A，全部通过才进入安装）

| # | 检查项 | 通过标准 |
|---|---|---|
| A1 | 仓库身份与出处 | 官方归属可验证（作者/组织与 Convai Innovations 关系可查）；不是同名撞车仓库 |
| A2 | 许可证 | LICENSE 文件存在且为 Apache 2.0 |
| A3 | 安装路径 | 官方声明的安装方式明确（PyPI 包名 or git+https）；**PyPI 存在同名包时必须核对发布者/仓库链接一致，防 typosquatting** |
| A4 | 安装钩子 | setup.py / pyproject 无 install 阶段任意命令执行（无 curl\|bash、无 base64/exec、无网络下载副作用） |
| A5 | 权重来源与格式 | 权重托管于 HuggingFace 等可溯平台；**仅 safetensors（拒绝 pickle .bin）**；有可核对的文件清单 |
| A6 | 仓库静态扫描 | clone 浅克隆后全库 grep：无 base64 解码执行、无 eval/exec/pickle.loads 加载不可信数据、无混淆长串、安装文档无「curl \| sh」类指令 |
| A7 | 依赖面 | requirements 可审（无未知私有源）；不强制拉起常驻网络服务 |
| A8 | 社区信号 | stars/forks/issues 活动与「官方项目」口径相符；无 GitHub 安全公告 / 已知投毒报告（GHSA 检索） |

**任何一项不过 → 停止，报告并关闭本批。**

## 3. 评测设计（ST-B/ST-C，审查通过后）

- **环境隔离**：独立临时 venv（不进项目 venv、不进 requirements.txt），权重下载到临时目录，评测结束整体删除；
- **场景 1 任务状态分类**：`seed_demo_data.py` 数据集 24 个任务（ground truth = 播种状态 todo/in_progress/done），LAYA 三选一 vs 现有规则引擎（`agent.py` 的建议逻辑）；
- **场景 2 留言审核**：15 条留言（ground truth = moderation_flagged/is_deleted + 人工复核），二分类；样本量小，报告如实标注统计效力有限；
- **指标**：准确率、单条延迟（LAYA 口径 33ms 需自证）、规则引擎基线对比；
- **判据（预先写死，防事后挪门柱）**：LAYA 在两场景合计准确率 ≥ 规则引擎 +10 个百分点，且单条延迟 < 500ms（CPU）→ 建议接入；否则 → 不接入，报告留档。

## 4. 不做

- 权重/依赖不入仓库、不进 requirements.txt（若接入，走 `requirements-laya.txt` 可选文件，另行批次）；
- 不在未审查通过前 pip install / 下载任何权重；
- 扩展侧集成不在本批（421M 模型浏览器下载需独立 opt-in 设计）。

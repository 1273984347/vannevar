3. 打 tag `v0.2.0` 并创建 GitHub Release，发布说明 = CHANGELOG 0.2.0 节中文原文 + 英文对译。

## 2. 范围与验收

| 步骤 | 内容 | 验收 |

| ST-A | CHANGELOG 定版 + Documentation 补记 README.en | 节标题/URL 引语格式与 0.1.0 一致 |
| ST-B | README.md 加切换入口；新建 README.en.md（徽章/首屏图卡/全部章节对译，路径与命令保持不变） | `qa_all` links PASS（含新文件）；两版互链可达 |

| 风险 | 应对 |
|---|---|

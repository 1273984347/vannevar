## 4. 发现的问题清单

### F-1（P2 · 文档缺口）根 README 测试命令缺 `requirements-dev.txt` 安装步骤

- **现象**：严格按根 README「开发与测试」一节操作，装完 `requirements.txt` 后直接 `py -m pytest` → `No module named pytest`，新用户必然卡住。
- **根因**：`requirements.txt` 自述「测试依赖已移至 requirements-dev.txt（V6 修复，不进生产镜像）」，产品级 README（`products/bridge-mvp/README.md:108` 写的是 `pip install -r requirements.txt -r requirements-dev.txt`）与 `docs/deploy-guide.md:240` 均已同步，唯独**根 README** 与 **AGENTS.md 测试速查**未同步。
- **建议修复**：根 README 测试命令代码块前补一行 `python -m pip install -r requirements-dev.txt`（或并入 install 命令）；AGENTS.md §4 同步。责任人：发布负责人；预计 10 分钟；验收 = 按根 README 从零走一遍 pytest。

### F-2（P3 · 文档漂移）测试基线数字过时

| 项 | 文档（根 README + AGENTS.md） | 实测（新克隆） |
|---|---|---|
| Focus 同步加密 | 12 通过 | 14 通过 |
| Muse 同步加密 | 14 通过 | 16 通过 |
| Bridge pytest | 447 passed | 449 passed |

- 根 README 的 pytest 行带「用例数随新功能递增」缓冲语，AGENTS.md 是硬基线表述，两者都建议更新为实测值。node 测试行无缓冲语，直接改数即可。

### F-3（P3 · 文档瑕疵）QUICKSTART 方式一 PowerShell 块混用 `py` 与 `python`

`py -m pip install`（装依赖）与 `$env:BRIDGE_JWT_SECRET = python -c …`（生成密钥）混用；在只有 Python Launcher 的机器上第二行会命中 Microsoft Store 占位符。根 README 对此有提示（「把上面的 python 换成 py」），QUICKSTART 该块未带同样提示。建议统一为 `py` 或补同款括号提示。

### F-4（状态提醒）本地领先 origin/main 1 提交未推送

`0ecd703 chore: gitignore 增补 AI 工具状态目录忽略` 尚在本地，GitHub 上的 `.gitignore` 缺该增补。影响极小，但「GitHub 为准」的口径下应推送对齐。

# T-05 · GitHub 公开仓展示面打磨 · 执行前计划

- 日期：2026-11-03
- 执行者：AI Agent（ZCode）
- 触发：用户指令「打磨 GitHub 公开仓库展示面」

## 0. 关键发现（本批最高价值）

`screenshots/vannevar-{focus,muse,bridge}-screenshot.png` 三张被 QUICKSTART 引用为「官方截图」的图，实为**带「TRAE AI 创造力大赛」页眉/页脚烙印的创意提案海报**（1280×1360~1511 竖版）。文本层 `TRAE` 全仓 0 命中 —— 烙印只存在于这 3 个 PNG 的像素里。T-01 遗留风险 R-05 曾标记「视频可能含参赛烙印」，**截图同类问题漏网**。它们一旦放上 README 首屏即构成开源项目的品牌污染。

## 1. 目标

让仓库门户（README 首屏、QUICKSTART、Assets 树）以真实产品 UI 面貌示人，清除展示面上最后一处参赛烙印，补齐社媒预览建议。

## 2. 范围

### 做

| 步骤 | 内容 | 验收判据 |
|---|---|---|
| ST-A | 选定真实产品 UI 截图（已审图）：Focus=`focus-popup-expanded.png`（360×600）、Muse=`muse-dashboard.png`（1280×800）、Bridge=`bridge-stats.png`（1280×800，bridge-detail/home 因含「截图测试项目」字样弃用） | 三图无参赛烙印、无测试痕迹字样（已逐一目检） |
| ST-B | README 首屏视觉化：徽章区下新增三图产品卡（HTML table 控宽）；删除徽章区过时的「静态徽章」HTML 注释（CI 徽章现已真实）；补 Release 徽章 | 渲染验证见 ST-E |
| ST-C | QUICKSTART 三处「截图」指向改到干净 UI 图；`git rm` 三张参赛海报 PNG | 被删文件全仓引用数 = 0（删前核）；`qa_all --only links` PASS |
| ST-D | 生成社媒预览卡候选图（1280×640，PIL 合成，置于仓库外），供手动上传 Settings → Social preview（该设置无公开 API） | 文件存在且尺寸正确；是否采用由用户定 |
| ST-E | 提交（显式 pathspec）+ 推送 + CI；用 `gh api .../readme`（HTML 渲染）核验图片可解析 | CI 绿；渲染 HTML 含 camo 图片 URL |
| ST-F | CHANGELOG `Unreleased` Documentation 补记 | 与实改一致 |

### 不做

- 不动 dependabot.yml / CI workflows / About 描述与 topics（现状已良好：描述一句话 + 13 个 topics + 社区标准 health 100%）；
- 不做版本发布（v0.2.0）—— 版本节奏与发布说明是独立决策，收尾时向用户提议；
- 不重录品牌视频（T-01 R-05 遗留，无 ffmpeg，另行批次）。

## 4. 复盘与经验

- **E-1（双语漂移）**：`README.en.md` 是中文版的快照式对译，从现在起**改中文版根 README 时必须同步英文版**（建议把「README.md 与 README.en.md 同步」视作 AGENTS.md §6 文档矩阵的一行；本批先在此留痕）。
- **E-2（定版节奏）**：0.1.0 → 0.2.0 间隔 9 天，Unreleased 积累量适中；后续建议每批收口时评估是否顺手定版，避免 Unreleased 无限膨胀。
- **E-3**：`--only links` 等单步门禁依赖前置产物（dist zip）——单步跑失败先看是不是「产物缺失」而不是「链接坏了」（本批再次踩到，已在前批清理 dist 后复现）。
